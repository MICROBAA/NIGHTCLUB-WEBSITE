# Tropical Salou

Modern website for Tropical — club, disco and restaurant in Salou.

Pages: home, events and tickets, the club, Tropical Fusion, menu, gallery, VIP, contact, legal notice. Spanish and English. Reservation requests open WhatsApp; nothing is charged on the site.

Open `index.html` or serve the folder:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```
