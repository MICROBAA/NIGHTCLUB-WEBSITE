# VOLTA

Modern website for VOLTA — club, sound and kitchen in Salou.

Pages: home, events and tickets, the club, VOLTA Kitchen, menu, gallery, VIP, contact, legal notice. Spanish and English. Tickets are sold online with card or Bizum payment; VIP and restaurant requests open WhatsApp.

Open `index.html` or serve the folder:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```
